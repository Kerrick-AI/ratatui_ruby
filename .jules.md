# Before Starting Work

Before starting work, you must do the following:

<pre>
git clone <your-repo-url>
cd <your-repo-name>

# Trust the configuration to allow environment variable loading
mise trust

# Installs Ruby 4, dependencies, and hooks
bin/setup
</pre>
